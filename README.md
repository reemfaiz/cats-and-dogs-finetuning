# Cats and Dogs Classification with Fine-Tuning

An image classification project that fine-tunes a pre-trained model to classify images of cats and dogs.

## Overview
- Using transfer learning / fine-tuning on a pre-trained CNN model
- Training and evaluating the model on a cats vs. dogs dataset
- Adjusting model layers and hyperparameters to improve accuracy

## Files
- `Day2_2_Finetuning_CatsAndDogs_Updated.ipynb` — Jupyter notebook containing the full code

## Requirements
- Python
- TensorFlow / Keras or PyTorch (depending on what's used in the code)
- NumPy, Matplotlib
